Antumbra Live

A virtual Antumbra phone you can use from this browser.

This is a virtual phone on GitHub's computer, not your phone. It ends by itself, and everything on it is wiped.

GitHub's machine and Cloudflare carry the screen. Never sign in to real accounts, and never type real passwords or personal details in it.

Reading the session's state…

The password is the repository secret ANTUMBRA_LIVE_PASSWORD. It never leaves this browser: the page turns it into a key that works for this session only.

What to do

  1. Wait until the box above says the phone is ready (about 10 minutes after the link appears).
  2. Type the password and tap Open the phone.
  3. Welcome is on the screen. To install apps, turn Administration on, then tap Start Antumbra. The virtual Wi-Fi is joined for you after Start.
  4. When Tor is connected, open F-Droid or Aptoide from the app drawer (swipe up on the home screen) and install apps. Everything goes through Tor, so it is slower than usual. If a store is missing, the box above says why.
  5. Tap to tap; drag to swipe. To press and hold (an app's menu, selecting text), keep your finger still for about two seconds.
  6. To type, tap Keyboard at the top of the phone's page, or use Android's own keyboard on the phone's screen.

The buttons beside the phone

The toolbar's top row (× and –) is left out of the picture on purpose: × would switch the virtual phone off at once. Powering the phone off ends the session early, and its own recording of the network is then lost. To stop, use End the session now above, or cancel the run in the GitHub app.

Limits

  • It is an x86_64 virtual phone: apps built only for phone (ARM) processors do not install.
  • No Google Play services: apps that need them complain or stop.
  • Slower than a real phone. One session at a time.
  • No sound and no camera: the virtual phone has neither, and this page carries only the screen.
  • At the end, the virtual phone's network traffic is checked for leaks; the run's summary on GitHub shows the result.
