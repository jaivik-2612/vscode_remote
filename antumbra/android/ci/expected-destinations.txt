# listed and noted; in strict mode it fails the run.

#   name PATTERN      a name, or *.NAME for NAME and every name under it
#   target HOST:PORT  an address or name and a port; either may be *

# Add an entry only with the reason next to it. Android's own background
# services (connectivity checks, network time, location assistance) are
# switched off by the module and must not appear here.
